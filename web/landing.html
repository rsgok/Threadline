03 / A FEW GOOD QUESTIONS

Before you
pick up the thread.

What is Threadline?+

Threadline is a local Mac app and runtime sidebar for saving useful parts of AI conversations. Keep original messages, add your own interpretation, and reuse what you’ve learned in your next discussion.

Which AI tools does it work with?+

Threadline reads locally available Codex and Cursor Agent transcripts. You can also add notes manually and copy combined notes into other AI tools. It doesn’t download cloud conversation history.

Does my library stay local?+

Yes. Notes and saved attachment copies live on your Mac. Sharing to a connected service sends only the content you explicitly choose. Remote image links remain links rather than being automatically downloaded.

Can I install it today?+

The current version runs from a local source checkout and requires macOS 13 or later, Node.js 22.13 or later, and Swift 5.9 or later. There isn’t a standalone app download yet. Follow the setup below if you have the source.

Set up Threadline for Mac ↗

Start from your local source checkout

Requires macOS 13+, Node.js 22.13+, and Swift 5.9+. Run these commands in the Threadline project folder.

npm ci
bash scripts/start-web.sh
bash scripts/install-mac.sh
bash scripts/install-skill.sh

Then open Threadline from your Applications folder. The app currently uses your local Node.js installation.
