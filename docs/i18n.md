# Interface languages

Threadline supports Simplified Chinese (`zh-CN`) and English (`en`). The saved preference is `system`, `zh-CN`, or `en`; a system language beginning with `zh` resolves to Simplified Chinese, and all others resolve to English.

Open **Settings / 设置** using the gear next to Search or from the Mac menu. Language and connection settings live on this dedicated page; Back returns to the previous conversation without changing selection. Applying a language saves pending editor changes, preserves this tab's drafts and message selection in a one-use session snapshot, and reloads the UI. Each browser profile stores its preference locally under `threadline-language`. The native web view sends the preference through a main-frame, localhost-validated bridge so macOS menus use the same language.

## Adding copy

- `web/i18n-catalog.js` maps application-owned Chinese source strings to English. Source strings act as catalog keys; add a translation whenever adding UI copy
- Use `I18n.t('界面语言')` for a literal, and a tagged template such as ``I18n.t`已选 ${count} 条` `` for dynamic copy. The catalog key uses `{0}`, `{1}`, etc. Translations may reorder placeholders; interpolated values remain unchanged
- Use `I18n.count(value, 'message' | 'note' | 'attachment')` for counts and `I18n.locale` for `Intl` dates and numbers
- Translate errors at the API boundary with `I18n.message`. It supports known exact messages and templates; preserve `rawMessage` for error classification
- Static HTML is translated once, before application data is rendered. Dynamic UI strings are translated at their call sites. Do not observe or rewrite the DOM after user content is inserted
- Never pass note bodies, titles, messages, code, filenames, recipient names, or URLs through translation. Translate surrounding application labels instead
- Option values, runtime IDs, routes, and stored content are language-independent. Imported Markdown role headings are parsed in their original language
- The image export stores its locale in the preview job. It localizes generated labels and continuation headings while retaining original messages and code
- Native menu and alert strings are handled by `tr` in `Sources/Threadline/main.swift`

Run `npm test` and `swift test`. `web/i18n.test.mjs` verifies fallback, persistence, native notifications, interpolation safety, catalog coverage, errors, plural forms, and exported labels. Also verify the rendered settings dialog and narrow English layouts in a named browser session, and close that session afterward.
